# DAA Assignments

This folder now contains separate standalone C programs for each algorithm/topic.

## Files

- [8queen.c](8queen.c) - 8-Queen problem using backtracking
- [bellman_ford.c](bellman_ford.c) - Bellman-Ford algorithm
- [binary_search.c](binary_search.c) - binary search using divide and conquer
- [bfs.c](bfs.c) - breadth first search
- [dfs.c](dfs.c) - depth first search
- [dijkstra.c](dijkstra.c) - Dijkstra's algorithm
- [floyd_warshall.c](floyd_warshall.c) - Floyd-Warshall algorithm
- [graph_coloring.c](graph_coloring.c) - graph coloring using backtracking
- [job_sequencing.c](job_sequencing.c) - job sequencing with deadlines
- [knapsack_greedy.c](knapsack_greedy.c) - 0/1 knapsack using greedy heuristic
- [kruskal.c](kruskal.c) - Kruskal's algorithm
- [matrix_chain_multiplication.c](matrix_chain_multiplication.c) - matrix chain multiplication using dynamic programming
- [max_min_divide_conquer.c](max_min_divide_conquer.c) - maximum and minimum in an array using divide and conquer
- [merge_sort.c](merge_sort.c) - merge sort
- [quick_sort.c](quick_sort.c) - quick sort
- [prim.c](prim.c) - Prim's algorithm
- [tsp_dp_branch_bound.c](tsp_dp_branch_bound.c) - travelling salesman problem using dynamic programming / branch and bound
- [DAA_Assignments.md](DAA_Assignments.md) - consolidated theory writeup

## Compile

Use GCC from this folder, for example:

```bash
gcc binary_search.c -o binary_search.exe
gcc merge_sort.c -o merge_sort.exe
gcc quick_sort.c -o quick_sort.exe
```

## Notes

- Each program is standalone and has its own `main()` function.
- Sample input/output is included in comments inside the source files.
